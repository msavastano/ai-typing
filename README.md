# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c1563f4b-46bd-4182-8920-9f70f2c51c2c

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Add your Anthropic API key in the app: sign in, then go to **Dashboard → Anthropic API key**.
   Create a key in the [Claude Console](https://platform.claude.com/settings/keys).
   Lessons are generated by Claude Haiku 5.5 (`claude-haiku-5-5`).
   The key is stored only in your browser session (cleared when you close the tab or sign out) —
   it is never written to `.env` or sent to our servers.
